# Сьорбати Можна · Школа чаю

Static site for a Ukrainian tea course: 4 modules, 13 video lessons, a quiz after each lesson, and a tea-kinds reference page with a PDF.

Live: https://siorbaty-mozhna.com (siorbaty-mozhna.pages.dev redirects there)

## Structure
- `index.html`, `module.html` (`#02-2` = module 02, lesson 2), `login.html`, `vydy-chaiu.html` and `voda.html` (generated by `scripts/build_teas.py`)
- `assets/`: styles, script, compressed photos, illustrations, hero video, PDF
- `modules/*.json`: course data, generated by `scripts/build_modules.py`
- `scripts/`: build and deploy scripts
- `functions/`: login gate (`_middleware.js`) and auth API (`api/auth/`), Cloudflare Pages Functions with a D1 database (`migrations/`, `wrangler.toml`)

Source content (transcripts, drafts, original photos and artwork) is kept in a separate private `Content/` folder that is not part of this repository, so the build scripts that read from it won't run from a fresh clone.

## Login
Everything except the home page needs an account. Only emails on the allowed list can register; they confirm the address through an emailed link, then log in with email and password.
```sh
sh scripts/students.sh add student@example.com   # allow a student (also: remove, list)
```
Or through the Telegram bot (`functions/api/telegram.js`): send it one or more emails to add students (each gets an invite email), `/remove`, `/invite`, `/list`. Set it up once with `sh scripts/telegram-setup.sh`; only Telegram IDs in `TELEGRAM_ADMINS` (`wrangler.toml`) can use it.

Emails go through Resend from `siorbaty-mozhna.com` (secret `RESEND_API_KEY`). Locally (`npx wrangler pages dev dist`, `--local` for students.sh) the links are printed to the console instead.

## Deploy
```sh
sh scripts/deploy.sh   # copies site files to dist/ and deploys to Cloudflare Pages
```
